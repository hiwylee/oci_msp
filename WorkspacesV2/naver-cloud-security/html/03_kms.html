암호화 키 관리

OCI Vault / KMS — HSM 기반 키 보호, Secret 관리, CMK 적용

"키를 잃으면 데이터를 잃습니다. OCI Vault는 암호화 키를 HSM 안에 가두고, 코드에서 DB 비밀번호를 없애줍니다. 키 관리는 보안의 마지막 보루입니다."

1. Vault 및 Master Key 생성

콘솔

  1. Identity & Security > Vault
  2. Create Vault 클릭 — Name: prod-vault, Vault Type: Virtual Private Vault (전용 HSM)
  3. Vault 생성 후 → Master Encryption Keys 탭 → Create Key
  4. Protection Mode: HSM (권장), Algorithm: AES-256

💡 Virtual Private Vault vs Default Shared

Virtual Private Vault는 비용이 높지만 키가 전용 HSM 파티션에 격리됩니다. 규제 대응 또는 고보안 환경에서 권장합니다.

OCI CLI

bash
# Vault 생성
oci kms management vault create \
  --profile YWDCLOUD \
  --compartment-id <compartment-ocid> \
  --display-name "prod-vault" \
  --vault-type DEFAULT

# Vault Management Endpoint 확인
oci kms management vault get \
  --profile YWDCLOUD \
  --vault-id <vault-ocid> \
  --query 'data."management-endpoint"' \
  --raw-output

# AES-256 마스터 키 생성
oci kms management key create \
  --profile YWDCLOUD \
  --compartment-id <compartment-ocid> \
  --display-name "prod-master-key-aes256" \
  --key-shape '{"algorithm":"AES","length":32}' \
  --protection-mode HSM \
  --endpoint <management-endpoint>

2. Block Volume에 CMK 적용

bash
# Block Volume 생성 시 CMK 적용
oci bv volume create \
  --profile YWDCLOUD \
  --availability-domain <ad-name> \
  --compartment-id <compartment-ocid> \
  --display-name "encrypted-volume" \
  --size-in-gbs 100 \
  --kms-key-id <key-ocid>

# 기존 볼륨에 CMK 적용 (재암호화)
oci bv volume update \
  --profile YWDCLOUD \
  --volume-id <volume-ocid> \
  --kms-key-id <key-ocid>

3. Object Storage에 CMK 적용

bash
# 버킷에 CMK 적용
oci os bucket update \
  --profile YWDCLOUD \
  --namespace <namespace> \
  --bucket-name <bucket-name> \
  --kms-key-id <key-ocid>

# 버킷 암호화 설정 확인
oci os bucket get \
  --profile YWDCLOUD \
  --namespace <namespace> \
  --bucket-name <bucket-name> \
  --query 'data."kms-key-id"'

4. Secret 관리 (DB 자격증명 코드 제거)

bash
# 시크릿 생성 (Base64 인코딩 필요)
SECRET_VALUE=$(echo -n "MyDBPassword123!" | base64)

oci vault secret create-base64 \
  --profile YWDCLOUD \
  --compartment-id <compartment-ocid> \
  --vault-id <vault-ocid> \
  --key-id <key-ocid> \
  --secret-name "prod-db-password" \
  --secret-content-content "$SECRET_VALUE"

# 시크릿 값 조회
oci secrets secretbundle get \
  --profile YWDCLOUD \
  --secret-id <secret-ocid> \
  --query 'data."secret-bundle-content".content' \
  --raw-output | base64 --decode

# 시크릿 목록 조회
oci vault secret list \
  --profile YWDCLOUD \
  --compartment-id <compartment-ocid> \
  --vault-id <vault-ocid> \
  --output table

5. 키 회전 (Key Rotation)

bash
# 키 버전 생성 (= 키 회전)
oci kms management key-version create \
  --profile YWDCLOUD \
  --key-id <key-ocid> \
  --endpoint <management-endpoint>

# 키 버전 목록 확인
oci kms management key-version list \
  --profile YWDCLOUD \
  --key-id <key-ocid> \
  --endpoint <management-endpoint>

💡 키 회전 후 동작

키 회전 후 기존 데이터는 이전 키 버전으로 복호화 가능하며, 신규 암호화는 새 버전을 사용합니다.

IAM Policy

hcl
# 키 관리 권한 (key-admins 전용 그룹)
Allow group key-admins to manage keys in compartment prod-compartment
Allow group key-admins to manage vaults in compartment prod-compartment

# 애플리케이션 Secret 조회 (Instance Principal)
Allow dynamic-group prod-instances to read secret-family in compartment prod-compartment
