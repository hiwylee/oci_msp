Cloud Guard

보안 위협 탐지 및 OS 보안 — 설정 오류, CVE, 위협 행위 자동 탐지

"설정 오류는 공격자의 문입니다. Cloud Guard는 그 문이 지금 열려 있는지 24시간 알려줍니다. 단, Auto Responder를 바로 켜면 운영 중인 서버가 갑자기 멈출 수 있습니다. Notify 먼저, Auto는 검증 후입니다."

4가지 Detector 유형 — OS 보안 탐지 항목

Configuration Detector (설정 오류)
  • Instance publicly accessible — 공인 IP + 0.0.0.0/0 허용 [Critical]
  • SSH port publicly exposed — 포트 22 인터넷 오픈 [Critical]
  • Instance has open ports — 불필요한 포트 노출 [Medium]
  • Boot volume not encrypted [Medium]
  • Block volume not encrypted [Medium]
Threat Detector (위협)
  • Anomalous instance activity — 비정상 API 호출 패턴 [High]
  • Credential theft — IMDS 비정상 접근 [Critical]
  • Privilege escalation — IAM 권한 비정상 변경 [Critical]
Activity Detector (활동)
  • Unusual user activity — 비정상 시간대/리전 조작 [High]
  • Instance console connection — 비상 접근 [Medium]
Log Insight Detector (로그 패턴)
  • Vulnerability found — CVE CVSS 7.0+ 발견 [High+]
  • OS patch not up to date — 30일 초과 미패치
  • Agent not running — Cloud Agent 30분 미응답
  • Root login enabled — PermitRootLogin yes 탐지
  • Password auth enabled — PasswordAuthentication yes

⚠️ Log Insight Detector 주의

OS 항목은 Vulnerability Scanning Service와 OS Management Service가 활성화되어 있어야 탐지됩니다.

1. Cloud Guard 활성화

bash
# Cloud Guard 활성화
oci cloud-guard configuration update \
  --profile YWDCLOUD \
  --compartment-id <tenancy-ocid> \
  --status ENABLED \
  --reporting-region <region>

# Target 목록 확인
oci cloud-guard target list \
  --profile YWDCLOUD \
  --compartment-id <tenancy-ocid> \
  --output table

2. Problem 확인

bash
# 현재 열린 Problem 목록 (HIGH 이상)
oci cloud-guard problem list \
  --profile YWDCLOUD \
  --compartment-id <compartment-ocid> \
  --compartment-id-in-subtree true \
  --risk-level HIGH \
  --lifecycle-state OPEN \
  --output table

# 인스턴스 관련 Problem만 필터
oci cloud-guard problem list \
  --profile YWDCLOUD \
  --compartment-id <compartment-ocid> \
  --compartment-id-in-subtree true \
  --resource-type Instance \
  --lifecycle-state OPEN \
  --output table

3. OS Management Service 활성화

bash
# OS Management + Vulnerability Scanning 에이전트 동시 활성화
oci compute instance update \
  --profile YWDCLOUD \
  --instance-id <instance-ocid> \
  --agent-config '{
    "plugins-config": [
      {"name": "OS Management Service Agent", "desired-state": "ENABLED"},
      {"name": "Vulnerability Scanning", "desired-state": "ENABLED"}
    ]
  }'

# 보안 점수 조회
oci cloud-guard security-score-aggregation list \
  --profile YWDCLOUD \
  --compartment-id <tenancy-ocid>

4. Responder Recipe (자동 대응)

Responder 유형동작운영 위험도
DISABLE_PUBLIC_IP공인 IP 제거높음 — 접근 불가

⚠️ 자동 대응 주의사항

처음에는 반드시 알림(Notification) 모드로만 운영하고, 충분한 검증 후 자동화하세요. Auto Responder 오동작으로 운영 서버가 중지될 수 있습니다.
